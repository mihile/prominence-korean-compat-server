# 생명력 부적 밸런스와 소지품 보존

Prominence II 4.1.5의 `zenith_attributes:vitality|2` 제한을 현재 Zenith 구현에 맞게 적용한다. 여기의 `2`는 내부 효과 증폭값으로, 정확히 증폭값 2인 부적이 대상이다. 대상 조합의 새 부적 제작은 기존 Zenith의 제한 판정을 통해 막는다.

기존 서버 설정은 제작 불가 부적을 자동 삭제한다. 이미 가진 해당 생명력 부적이 삭제되지 않도록, 서버의 부적 효과 처리 초입에서 이 조합만 중단한다. 아이템은 보존되고 제한된 효과는 적용되지 않는다. 다른 부적과 다른 증폭값은 기존 경로를 따른다. 기존 `Yeet Uncraftable Charms` 설정은 변경하지 않는다.

Minecraft 1.20.1, Zenith 2.0.2, Zenith Attributes 1.0.3과 원본 세 클래스의 SHA-256이 모두 맞을 때만 두 Mixin을 함께 적용한다. 대상이 다르면 두 수정 모두 비활성화한다. 원본 모드 파일은 변경하지 않는다.

정식 서버 JAR 하나만으로 이 항목이 작동하며 별도 config 변경은 필요하지 않다. 이 JAR은 다른 4.1.5~4.1.6 밸런스 설정, 망치 모드 또는 데이터팩을 자동 배포하지 않는다.

## 검증

- 실제 설치된 Zenith 두 클래스에 Sponge Mixin 변환 및 ASM 검증.
- 실제 배포 JAR의 Mixin 핸들러와 작은 API fixture로 생명력 부적 보존/효과 차단, 다른 효과·다른 레벨·비플레이어 불간섭 검사.
- 가드 일치/버전 및 각 클래스 불일치 검사.
- 기존 서버 클래스와 updater 바이트 보존, updater 회귀 검사.
- Minecraft와 운영 서버를 새로 실행하지 않았다. 실제 게임에서의 제작 UI와 아이템 처리는 적용 후 확인이 필요하다.
