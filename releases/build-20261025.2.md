**서버를 켜면 새 패치를 확인하고, Minecraft가 시작되기 전에 자동으로 적용합니다.** 기존 stop·crash 후 자동 재시작에서도 확인하며, 업데이트를 위한 추가 재시작은 필요하지 않습니다.

처음 설치할 때는 서버와 기존 자동 재시작 창을 모두 종료하고 **`server-updater-bootstrap.zip`**을 서버 폴더에 풀어 설치하세요. 이후에는 기존 `start.bat`을 사용합니다. 이미 자동 업데이트를 설치했다면 JAR 업데이트로 적용됩니다.

<details>
<summary>✨ 시작 전 자동 업데이트</summary>

- GitHub의 서버 전용 서명 피드에서 새 빌드를 확인합니다.
- 다운로드·서명·SHA-256·크기·빌드를 검증한 뒤 JAR 한 개만 교체합니다.
- 인터넷 연결이나 다운로드에 실패하면 기존 패치로 시작합니다.
- 이전 `prominence-korean-compat-1.0.0.jar`은 백업한 뒤 서버 이름으로 이전합니다.
- 이번 빌드는 **서버 종료 중 미리 적용한 준비본과 실제 기동 시도를 구분**합니다. 아직 서버를 켜지 않은 상태를 실패로 판단해 되돌리지 않습니다.

</details>

<details>
<summary>🔎 복구와 적용 범위</summary>

새 버전은 기동 완료 후 60초 이상 실제 서버 틱이 진행되어야 정상으로 확정됩니다. 그 전에 종료하거나 기동에 실패하면 다음 시작 전에 이전 JAR로 복구하고 같은 실패 빌드를 차단합니다. 교체 중 중단된 경우에도 기록과 백업으로 복구합니다.

백업 손상이나 수동 파일 교체처럼 안전하게 판단할 수 없는 상태에서는 자동 재시작 루프를 멈춥니다. 다른 모드·설정·월드·Java/JVM 옵션은 바꾸지 않습니다. 오프라인 검사와 공개 피드를 이용한 파일 적용·복구를 검증했으며 실제 서버의 첫 로드·월드 동작은 별도 검수가 필요합니다.

</details>
