# Skill Tree Presets

Pufferfish's Skills의 배분을 플레이어마다 **3개 프리셋**으로 관리합니다. 레벨·경험치·총 스킬 포인트는 공유하며, 현재 프리셋의 배분만 능력치에 적용됩니다.

현재 대상: Minecraft 1.20.1 / Fabric / Pufferfish's Skills 0.17.3 / SimplySkills 1.7.2+1.20.1 / Prominent 4.1.1. **서버 기능 + 선택 설치용 클라이언트 버튼 UI**로 구성합니다. 클라이언트 UI가 없어도 모든 프리셋 기능을 명령어로 사용할 수 있습니다. 유지보수 규칙에 따라 실제 설치본은 각각의 기존 `prominence-korean-compat-1.0.0.jar`에 통합합니다.

## 사용법

| 명령어 | 기능 |
|---|---|
| `/스킬트리` | UI가 있으면 스킬 화면, 없으면 한 줄 선택 메뉴 |
| `/스킬트리 프리셋1` 또는 `/스킬트리 궁수` | 기본 이름 또는 변경한 이름으로 전환 (공백 있는 이름도 지원) |
| `/스킬트리 이름변경 프리셋1 궁수` | 해당 프리셋 이름 변경, 1~32자 |
| `/skillpreset` 또는 `/skillpreset status` | 같은 선택 메뉴 |
| `/skillpreset use 2` | 현재 배분을 보존하고 2번으로 전환한 뒤 기존 스킬 화면 열기 |
| `/skillpreset name 2 마법사` | 프리셋 이름 지정, 1~32자 |
| `/skillpreset open` | 현재 프리셋의 기존 스킬 화면 열기 |

`/spreset`도 같은 명령어입니다. 일반 플레이어가 자기 프리셋을 관리하며 OP 권한은 필요 없습니다. 다른 플레이어의 데이터는 지정할 수 없습니다. UI가 있으면 전환·이름 변경 채팅을 표시하지 않습니다. UI가 없는 플레이어에게만 짧은 색상 메시지로 이전 값·적용 값·기본값을 안내합니다.

## 선택 설치용 클라이언트 UI

- 스킬 창 왼쪽 위 제목(현재 한국어 표시의 ‘유물’) 바로 옆에 **1 · 2 · 3** 버튼을 표시합니다. 제목 폭을 실제 게임 폰트로 계산합니다.
- 선택 중인 프리셋은 금색 테두리·밑줄로 강조하며, 다른 버튼은 짙은 청회색 바탕과 밝은 숫자로 구분합니다. 마우스 호버와 키보드 포커스, 내레이션을 지원합니다.
- 마우스를 올리면 프리셋 이름만 표시합니다. 오른쪽 연필 아이콘으로 현재 프리셋 이름을 바꿉니다. 번호를 클릭하면 서버가 배분을 전환하며 기존 창의 트리 탭·확대·이동 위치를 보존합니다. 유물 강화 탭에는 프리셋 UI를 표시하지 않습니다.
- 전환 중에는 중복 클릭을 막고, 서버 응답 뒤에만 선택 표시를 확정합니다. 실패하면 기존 번호를 유지하며, 응답이 없으면 상태를 다시 요청합니다.
- 버튼의 클릭·마우스 놓기가 뒤쪽 스킬 구매나 드래그로 전달되지 않습니다. 좁은 화면에서는 버튼 폭을 줄여 포인트와 경험치 바를 피합니다. 극단적으로 공간이 부족하면 겹쳐 그리지 않고 명령어를 사용할 수 있습니다.
- **UI 설치 여부는 접속 조건이 아닙니다.** 미설치 클라이언트는 기존 명령어를 사용하며, 지원하지 않는 서버에서는 버튼과 요청 패킷을 보내지 않습니다. 경험치·포인트·배분 판정은 모두 서버가 처리합니다.

서버는 `install.bat`으로 1.1.3 기능 준비본을 적용해야 합니다. 버튼을 원하는 클라이언트만 Minecraft를 종료한 뒤 `install-client-ui.bat`을 실행합니다. 기본 대상은 이번 준비본의 기준인 마스터 인스턴스이며, 다른 기존 호환 JAR과 해시가 다르면 덮어쓰지 않습니다. 다른 클라이언트 기준의 준비본은 `python tools/package_client.py --base "해당 클라이언트/minecraft/mods/prominence-korean-compat-1.0.0.jar"`로 만들 수 있습니다.

클라이언트용 통합본은 `build/payload/client/mods/prominence-korean-compat-1.0.0.jar`, 서버용은 `build/payload/server/mods/prominence-korean-compat-1.0.0.jar`입니다. 기존 호환 파일의 다른 기능을 보존하며 **역할에 맞는 파일을 사용**합니다. 선택 설치 파일을 준비하는 작업이므로 마스터·배포본·다른 플레이어에게 자동 적용하지 않습니다.

처음 적용하면 기존 배분은 **1번**으로 보존하고 2·3번은 미배분 상태로 시작합니다. 2번을 선택해 기존 스킬 화면에서 포인트를 배분하고, 3번도 같은 방식으로 구성하면 됩니다. 프리셋은 캐릭터 스킬 트리 `puffish_skills:prom`에만 적용합니다. 유물 강화 배분과 각 트리의 레벨·포인트는 기존 공통 상태를 유지합니다.

예를 들어 레벨에 따라 32포인트를 얻었다면 1번은 궁수, 2번은 마법사, 3번은 전사에 각각 32포인트를 배분할 수 있습니다. 새로 얻은 레벨과 퀘스트 등으로 받은 추가 포인트도 공유합니다. 다른 프리셋으로 갔다 돌아오면 그동안 배분하지 않은 새 포인트도 사용할 수 있습니다. 원래 스킬 트리의 사용 포인트 상한은 유지됩니다.

## 초기화권

- Prominent의 **지식의 두루마리**는 선택 중인 프리셋의 기본 스킬 트리 배분만 초기화합니다.
- **태고의 두루마리**는 원래 모드대로 해당 유물의 공통 강화 배분을 초기화합니다. 유물에는 프리셋을 만들지 않습니다.
- 다른 프리셋, 다른 스킬 트리, 레벨·경험치·총 포인트는 유지됩니다. 초기화권의 소비 방식은 원래 모드가 처리합니다.
- 원래 `/puffish_skills skills reset` API를 사용하는 다른 초기화도 같은 방식입니다. 무료 초기화/다른 슬롯 덮어쓰기 명령은 추가하지 않습니다.
- 관리자의 `category erase`는 경험치까지 지우는 별도 기능이므로, 해당 트리의 저장 배분도 모든 프리셋에서 제거합니다.
- 원래 모드의 유물 재귀속처럼 경험치를 명시적으로 0으로 지우는 동작도 해당 트리의 프리셋 배분을 정리합니다. 일반 초기화권은 경험치를 바꾸지 않으므로 이 경로에 해당하지 않습니다. 프리셋 전환 자체는 경험치를 지우지 않습니다.

## 저장과 전환

프리셋에는 배분한 스킬 ID와 이름, 선택 번호만 저장합니다. 경험치·레벨·포인트·트리 잠금 상태는 원래 Pufferfish 데이터 한 벌을 사용합니다. 전환 중 경험치나 포인트 설정 명령을 호출하지 않고, 일반 해금 이벤트도 재생하지 않습니다. 기존 능력치 보상과 SimplySkills 능력 표시 패킷을 갱신합니다.

기존 `world/data/puffish_skills.dat`의 각 플레이어 데이터 아래 `prominence_skill_presets`에 함께 저장합니다. 현재 배분은 전환할 때와 정상 서버 저장 때 자동 보존됩니다. 정상 재접속·사망·차원 이동·서버 재시작 뒤에도 유지되며, 강제 종료 시 마지막 정상 저장 이후의 변경은 원래 스킬 데이터와 함께 손실될 수 있습니다.

서버에 저장됐던 배분만 복원하며 임의의 스킬 목록을 클라이언트에서 받지 않습니다. 원래 모드가 자동 해금한 연결 지점도 배분대로 복원합니다. 스킬이 삭제되거나 포인트가 줄어 필요한 비용을 충족하지 못하면 전환을 거절하고 현재 배분을 보존합니다. 데이터팩 변경 후 기존 배분의 연결 조건을 새 구매 과정처럼 다시 실행하지 않습니다.

현재 캐릭터 트리에서 사용하는 attribute/passive_skill 보상을 대조했습니다. 실제 배분 개수가 바뀌는 보상에 부작용이 있는 미검토 유형이 추가되면 전환을 거절합니다. 관련 없는 다른 트리나 개수가 바뀌지 않는 보상은 전환을 막지 않습니다. 잘못된 프리셋 NBT는 원본을 보존하고 전환을 중단합니다. 대상 모드 버전이 달라지면 저장 형식 불일치로 프리셋이 유실되지 않도록 월드 로딩 전에 기동을 중단하므로 대상 API를 다시 검토해야 합니다.

## 설치

1. 서버를 정상 종료합니다.
2. 이 폴더의 `install.bat`을 실행합니다. 실행 중 서버가 있으면 파일 변경 전에 중단합니다.
3. 원래 방식으로 서버를 시작하고 `/skillpreset`을 입력합니다.

설치기는 기존 통합 JAR과 스킬 저장 데이터만 별도 백업하고, 검증된 통합 JAR 하나를 교체합니다. 서버를 자동 시작하거나 월드·설정을 수정하지 않습니다. 통합 JAR이나 대상 모드가 준비 이후 변경됐으면 기존 변경을 덮어쓰지 않도록 거절합니다. 그 경우 현재 파일을 기준으로 아래 패키징을 다시 수행합니다.

`build/libs/skill-tree-presets-1.1.3+1.20.1.jar`는 서버 기능만 담은 모듈 산출물이고, `client-ui/build/libs/skill-tree-presets-ui-1.1.3+1.20.1.jar`는 UI 모듈입니다. 이 팩에서는 통합 설치본과 동시에 별도 설치하지 않습니다.

## 빌드와 검증

JDK 21로 빌드하며 결과물은 Java 17 이상에서 실행합니다. Gradle Wrapper를 포함합니다. 서버의 `mods`에 해당 Pufferfish/SimplySkills JAR이 있는 현재 폴더 구성에서는 다음을 실행합니다.

```bat
gradlew.bat build
python tools/package.py
python tools/package_client.py
```

의존 JAR을 다른 위치에 두었다면 `-PpuffishSkillsJar=C:/path/puffish_skills.jar -PsimplySkillsJar=C:/path/simplyskills.jar`로 지정할 수 있습니다. 패키징은 이 프로젝트가 현재 서버의 `development/skill-tree-presets`에 있다는 전제이며, 기존 통합 JAR의 다른 파일을 바이트 단위로 보존합니다. 기존 모드 JAR을 결과물 안에 묶어 배포하지 않습니다.

단위 검증에는 3슬롯 격리, 초기화권과 같은 활성 배분 갱신, 정상 NBT 저장 왕복, 포인트·경험치 공유, 비용 검사, 실패 시 복원, 명령어 파싱, 설치된 모드의 실제 메서드 대상 검사를 포함합니다. 로컬 대상 JAR이 없으면 해당 대상 검사는 건너뜁니다. 서버 통합 패키징은 건너뛴 검사가 있으면 거절합니다.

서버 테스트 결과는 `build/reports/tests/test/index.html`, UI 테스트 결과는 `client-ui/build/reports/tests/test/index.html`입니다. 패키징 보고서는 `build/verification/build-report.json`과 `client-build-report.json`입니다. 단위 테스트와 바이트코드 대조는 실제 Mixin 변환·서버 기동·게임 화면·초기화권 사용 검수와 구분합니다. 이 작업에서는 Minecraft 서버나 월드를 실행하지 않습니다.

Pufferfish API와 초기화 개념 참고: [공식 모드 문서](https://modrinth.com/mod/skills).


## 1.1.2 수정

- 번호 버튼에 마우스를 올리면 기본은 프리셋1·프리셋2·프리셋3, 이름을 지정했다면 해당 이름만 표시합니다.
- 1·2·3 오른쪽 연필 아이콘에서 현재 프리셋 이름을 1~32자로 변경합니다. 명령어 이름 변경도 계속 지원합니다.
- 프리셋은 캐릭터 스킬 트리(puffish_skills:prom)에만 적용합니다. 유물 강화 탭에서는 버튼을 숨기고, 유물 배분은 모든 프리셋이 공통으로 사용합니다. 예전 프리셋의 유물 배분 사본은 전환에 사용하지 않습니다.
- 함께 로드된 다른 트리의 사용하지 않는 명령 보상 때문에 전환 전체가 막히던 오류를 수정했습니다. 검사 범위는 실제 배분이 바뀌는 캐릭터 트리 보상으로 한정합니다.


## 1.1.2 명령어·안내 개선

- UI 설치 클라이언트의 프리셋 전환/이름 변경은 채팅 없이 처리합니다. 오류는 UI/액션바로 표시합니다. UI가 없을 때만 짧은 색상 메시지를 표시합니다.
- `/스킬트리 <이름>`을 지원합니다. 기본 이름은 프리셋1·2·3이며 이름을 바꾸면 자동완성에도 바뀐 이름이 표시됩니다. 한글 이름에 언어별 제한을 걸지 않아 ko_kr 클라이언트와 UI가 없는 클라이언트 모두 사용할 수 있습니다. 중복 이름은 거절하고 `/스킬트리 1` 또는 기존 use 번호 명령으로 선택할 수 있습니다.
- 선택 클라이언트 패치에 /toomanyspawn 자동완성 툴팁을 추가합니다. ko_kr에서 한국어, en_us에서 영어로 표시하며 명령 토큰은 영어를 유지합니다. 스폰 모드를 클라이언트에 설치할 필요는 없습니다.


## 1.1.3 한국어 이름 변경

`/스킬트리 이름변경 프리셋1 궁수`를 추가했습니다. 프리셋1·2·3 번호 식별자는 이름을 바꾼 뒤에도 이름 변경 대상으로 사용할 수 있습니다. 현재 이름이나 1~3 번호도 지원합니다. 예: `/스킬트리 이름변경 궁수 저격수`, `/스킬트리 이름변경 2 냉기 마법사`. 공백 있는 대상은 따옴표로 지정할 수 있습니다. 기존 이름으로 지정하면 가장 길게 일치하는 현재 이름을 사용하며, 같은 이름이 여러 슬롯이면 번호를 요청합니다. 이름만 바꾸며 현재 선택과 배분은 바꾸지 않습니다.
